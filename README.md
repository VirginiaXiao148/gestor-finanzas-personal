# Gestión de Finanzas Personales

## Descripción

**Gestión de Finanzas Personales** es una aplicación de escritorio desarrollada en Java que ayuda a los usuarios a registrar y hacer seguimiento de sus inversiones y gastos, promoviendo una gestión financiera efectiva.

### Características principales:
- **Registro de inversiones**: Tipo de inversión, monto y fecha.
- **Registro de gastos**: Tipo de gasto, monto y fecha.

### Futuras funcionalidades:

- Versión para dispositivos móviles.
- Sincronización de datos entre dispositivos.

## Requisitos

- **Java 8** o superior.
- Sistema operativo compatible con aplicaciones de escritorio Java.

## Instalación

1. Clona este repositorio en tu máquina local:
   ```bash
   git clone https://github.com/usuario/repositorio.git
   ```
2. Asegúrate de tener instalado Java en tu sistema.
3. Compila y ejecuta el archivo principal desde tu entorno de desarrollo preferido o mediante la terminal:
   ```bash
   javac Main.java
   java Main
   ```

## Uso

1. Abre la aplicación.
2. Registra tus inversiones y gastos en las secciones correspondientes.
